## D02.2 — Classification comparability

**Review date:** 2026-10-25
**Status:** Partially established

### Confirmed from official metadata

The 2024 dataset uses the Canadian FBP fuel-type
framework and identifies three principal input sources:

- Spatialized Canadian National Forest Inventory (SCANFI)
- Canadian ecozones
- National Burned Area Composite (NBAC)

The dataset catalogue records:

- Publication date: 2024-04-01
- Metadata release date: 2024-07-10
- Temporal coverage: 2020-08-01 to 2024-04-01
- Named 30 m raster distribution: 2024-05-22

These dates do not establish the observation date
of every underlying landscape attribute.

### Comparability with 2019

Both products use FBP fuel-type terminology.

However, common fuel-type terminology does not
establish identical raster code assignments,
classification thresholds, or processing rules.

The 2019 decision-rules documentation cannot yet
be assumed to describe the 2024 classification.

### Outstanding questions

- Does the 2024 product retain the 2019 code mapping?
- Are mixedwood classification intervals unchanged?
- Which SCANFI version and attributes were used?
- Which NBAC edition contributed to the 2024 raster?
- Was the 2023 Westwood Hills footprint included?
- Were new or modified classification rules applied?

### Experimental implication

Compare code dictionaries before measuring
cell-level classification agreement.

Keep classification disagreement separate from
differences in resolution, source observation dates,
and actual landscape change.

## D02.3 — Source evidence and burned-area provenance

**Review date:** 2026-10-25
**Status:** Source families confirmed; versions unresolved

### Confirmed

The official 2024 FBP catalogue identifies three
principal source datasets:

- Spatialized Canadian National Forest Inventory (SCANFI)
- Canadian ecozones
- National Burned Area Composite (NBAC)

The catalogue does not identify the exact SCANFI
or NBAC version used to produce the raster.

### Relationship to newer products

The newer Canadian National FBP Fuel Type Layer
explicitly identifies SCANFI 2.0 and describes
annual incorporation of burned-area information.

This newer documentation does not establish
that the 2024 product used SCANFI 2.0 or the
same annual processing procedure.

### NBAC and the 2023 wildfire

NRCan maintains 2023 NBAC burned-area products.

However, currently distributed 2023 NBAC data
may incorporate revisions made after 2024.

We have not established:

- Which NBAC version informed the 2024 FBP raster.
- Whether the Westwood Hills footprint was included.
- How burned areas were translated into fuel classes.
- Whether affected cells represent post-fire vegetation.

### Experimental implication

We must distinguish:

1. Historical landscape change.
2. Changes in source evidence and its observation dates.
3. Changes in fuel classification procedures.
4. Revisions to retrospective burned-area products.

The 2023 fire footprint should be treated as
contextual evidence until its representation
within the 2024 fuel product is established.

Differences between the WMS and GeoTIFF should not
automatically be attributed to spatial aggregation.
Product-version and processing differences remain
possible.

No 2024-to-2026 cell-level classification comparison
has yet been performed.

documentation for explicit numerical code definitions,
particularly code 415.

Retain unresolved values without assigning speculative
fuel-family interpretations.

Verify categorical transformation and grid alignment
before calculating 2024-to-2026 classification differences.

### Source and extraction

The official 2024 WMS supports the GetStyles request,
returning an OGC Styled Layer Descriptor (SLD).

Service:

The returned SLD contains explicit numeric

The observed local code inventory was matched against
these published definitions.

The resulting register is:

`docs/datasets/fbp-2024-code-register.csv`

All 13 observed local codes appear in the published
2024 style.

### Previously unresolved classifications

- Code 105: Vegetated Non-Fuel
- Code 415: M-1 Boreal Mixedwood - Leafless (15% Conifer)
- Code 13: D-1/D-2 Aspen

These meanings are supported by the published style.
They supersede earlier statements in this document
that the classification meaning of code 415 was unknown.

### Spatial disagreement remains unresolved

Resolving the numerical code meaning does not explain
why the single 100 m raster cell assigned code 415
returned other classifications in nine queries
against the 30 m WMS.

Grid resolution, aggregation, alignment, and product
processing remain possible explanations.

The source does not establish the 100 m aggregation
method or cell-by-cell equivalence with the WMS.

### Implication for 2024–2026 comparisons

Numeric code equality must not be assumed to imply
equivalent classification meanings across editions.

In particular, the published 2024 style identifies
code 13 as D-1/D-2 Aspen, while the previously
documented 2026 register identifies it as vegetation
without an effective FBP type match.

Any cross-edition analysis must use version-specific
code dictionaries and explicitly distinguish numeric
disagreement from semantic disagreement.

the existing 2026 reference grid, using categorical
nearest-neighbour transformation.

Verify output geometry, coverage, code inventory,
and native-to-aligned classification preservation
before conducting paired comparisons.

## D05.17–D05.19 — Validated 2024 grid alignment

**Date:** 2026-10-26
**Status:** Completed; categorical alignment independently verified

### Method

The original national 2024 FBP raster was retained unchanged.

The 2026 study boundary was transformed into the
embedded CRS of the 2024 source raster.

A local native-grid crop was produced with a 300 m
margin around the transformed study boundary.

The cropped categorical raster was projected using
`terra::project(method = "near")`, with the existing
2026 study raster as the exact output template.

No continuous interpolation was used.

### Derived raster

`data/processed/study-window/fbp_2024_aligned_100m.tif`

The derived raster is excluded from Git along with
other processed raster data.

### Geometry and classification validation

- Native working crop: 207 × 207 cells
- Native working resolution: 100 m
- Aligned raster: 200 × 200 cells
- Aligned resolution: 100 m
- Total aligned cells: 40,000
- Missing aligned values: 0
- Unexpected numeric codes: 0
- Geometry matches 2026 reference: yes
- All 13 locally observed 2024 codes remain represented

### Independent preservation test

For each of the 40,000 output-cell centres:

1. Extract the centre coordinates from the aligned grid.
2. Transform those coordinates into the native 2024 CRS.
3. Extract the classification directly from the original
   national 2024 raster.
4. Compare this value with the saved aligned raster.

Results:

- Comparable cells: 40,000
- Matching classifications: 40,000
- Mismatches: 0
- Missing source values: 0
- Missing aligned values: 0

**Result:** Nearest-neighbour classification preservation
at output-cell centres verified for all 40,000 cells.

### Interpretation and limitations

The alignment introduces no observed disagreement
between saved output values and independent native-source
extractions at corresponding output-cell centres.

This does not validate the underlying fuel classifications.

It also does not establish equivalence between the 100 m
GeoTIFF and the separately published 30 m WMS.

The aligned file is a derived representation of the
2024 source, not an independent classification product.

### Next investigation

Perform paired 2024–2026 comparisons using their
respective verified code dictionaries.

Distinguish numeric equality from semantic equivalence
and report classification differences without attributing
them automatically to real landscape change.
