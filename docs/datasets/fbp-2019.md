## Classification characteristics

The product applies classification rules to multiple
landscape attributes.

The supporting base-layer documentation describes:

- Fuel versus non-fuel classification using 60% vegetation.
- Forest classification using 10% crown closure.
- Broadleaf and needleleaf composition thresholds.
- Mixedwood classifications using composition rules.

Mixedwood variants include numerical codes 625, 635,
650, and 665, among others.

The November 2019 update adjusted classifications of
low-quality balsam fir stands.

## Initial interpretation

The raster represents a modelled national fuel
classification rather than a direct 2019 vegetation survey.

Differences from later products may arise from changes in
source evidence, classification procedures, spatial
resolution, or actual landscape conditions.

The 2023 Westwood Hills fire occurred after this release.


## Detailed classification rules

The following rules are documented in NRCan's
November 2018 decision-rules and base-layer documents.

Their exact application to the November 2019 release
has not yet been independently verified.

### Vegetation and forest classification

| Condition | Initial classification |
|---|---|
| Vegetation < 60% | Nonfuel |
| Vegetation >= 60%, crown closure < 10% | Open |
| Vegetation >= 60%, crown closure >= 10% | Forest |

For forest-classified cells:

| Composition | Classification |
|---|---|
| Broadleaf > 75% | Deciduous |
| Needleleaf > 75% | Coniferous |
| Neither component > 75% | Mixedwood |

These are intermediate classification rules.
Subsequent decision rules may assign or modify
the final FBP fuel type.

### Mixedwood subdivision

For cells classified as mixedwood:

| Condition | Assigned fuel type |
|---|---|
| Crown closure <= 30% | D-1/2 |
| Crown closure > 30%, needleleaf > 25% and < 42% | M-1 C35 |
| Crown closure > 30%, needleleaf 42% to 58% | M-1 C50 |
| Crown closure > 30%, needleleaf > 58% and <= 75% | M-1 C65 |

The documented needleleaf calculation treats tamarack
as broadleaf for fuel classification purposes.

### Interpretation of C50

C50 denotes a classification category associated
with a range of needleleaf composition.

It does not establish that every mapped cell contains
exactly 50% coniferous vegetation.

A provincial inventory estimate differing from 50%
is therefore not, by itself, evidence of an error
in the federal classification.

### Implications for our experiments

Comparisons with provincial inventory should distinguish:

1. Agreement with the documented classification interval.
2. Differences in estimated vegetation composition.
3. Differences in crown closure and forest classification.
4. Differences in observation period and spatial support.
5. Differences arising from classification procedures.

The classification rules are not a substitute for
the original continuous vegetation attributes.

## Research implications

Spatial resolution and fuel classification differences
must be examined separately where feasible.

The 2019 map must not be assumed to describe conditions
observed uniformly during 2019.

The dataset is hosted in an NRCan development directory;
its production status requires appropriate qualification.
